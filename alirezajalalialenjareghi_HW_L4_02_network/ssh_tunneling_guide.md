# خلاصه جامع SSH Tunneling

SSH (Secure Shell) ابزاری قدرتمند برای برقراری ارتباط امن بین دو سیستم است و قابلیت "تونلینگ" آن، امکان عبور امن ترافیک شبکه از داخل یک اتصال SSH را فراهم می‌کند.

## 1. Local Port Forwarding

-   **مفهوم:** باز کردن یک پورت روی سیستم **محلی**؛ ترافیک آن پورت از طریق SSH به سرور **راه دور** و سپس به مقصد مشخصی هدایت می‌شود.
-   **فرمول:** `ssh -L local_port:destination_host:destination_port user@ssh_server`
-   **کاربرد:** دسترسی از سیستم خودتان به سرویس‌های داخلی (مانند دیتابیس) که در شبکه راه دور قرار دارند و مستقیماً در دسترس نیستند.
-   **مثال:** اتصال به دیتابیس MySQL داخلی از لپ‌تاپ شخصی.

## 2. Remote Port Forwarding

-   **مفهوم:** باز کردن یک پورت روی **سرور SSH راه دور**؛ ترافیک آن پورت از طریق SSH به سیستم **محلی** شما (یا شبکه‌ای که به آن دسترسی دارید) هدایت می‌شود.
-   **فرمول:** `ssh -R remote_port:destination_host:destination_port user@ssh_server`
-   **کاربرد:** در دسترس قرار دادن یک سرویس محلی (مانند اپلیکیشن در حال توسعه) از طریق یک سرور عمومی برای دیگران.
-   **مثال:** نمایش یک وب‌اپلیکیشن در حال توسعه به یک همکار از طریق سرور عمومی.

## 3. Dynamic Port Forwarding (SOCKS Proxy)

-   **مفهوم:** راه‌اندازی یک پراکسی SOCKS روی سیستم **محلی**؛ برنامه‌ها (مانند مرورگر) ترافیک خود را از طریق این پراکسی و سپس از تونل SSH عبور می‌دهند.
-   **فرمول:** `ssh -D local_port user@ssh_server`
-   **کاربرد:** مرور امن و ناشناس، دسترسی به منابع محدود جغرافیایی، یا عبور ترافیک چند برنامه از یک سرور واسط.
-   **مثال:** استفاده از مرورگر برای دسترسی امن به اینترنت از طریق سرور SSH.

---

**نکته کلیدی:** برای فعال نگه داشتن تونل SSH، پنجره ترمینال آن نباید بسته شود. استفاده از آپشن‌های `-f -N` برای اجرای تونل در پس‌زمینه توصیه می‌شود.
