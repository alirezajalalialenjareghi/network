# comparison

## 1) تفاوت FTP، SFTP و SCP

### FTP
- پروتکل قدیمی انتقال فایل است.
- از **دو کانال** استفاده می‌کند:
  - کانال فرمان
  - کانال داده
- معمولاً روی **پورت 21** کار می‌کند.
- **امن نیست**؛ نام کاربری، رمز عبور و داده‌ها به صورت متن ساده منتقل می‌شوند.

### SFTP
- مخفف **SSH File Transfer Protocol** است.
- روی **SSH** اجرا می‌شود، نه روی FTP.
- معمولاً از **پورت 22** استفاده می‌کند.
- **امن است** چون همه چیز رمزنگاری می‌شود.
- علاوه بر انتقال فایل، امکان مدیریت فایل هم دارد.

### SCP
- مخفف **Secure Copy Protocol** است.
- این هم روی **SSH** کار می‌کند.
- معمولاً از **پورت 22** استفاده می‌کند.
- **امن است** و برای کپی سریع فایل بین سیستم‌ها طراحی شده است.
- امکانات مدیریتی آن از SFTP کمتر است.

## 2) مزایا و معایب هر کدام

### FTP

**مزایا:**
- ساده و قدیمی و بسیار شناخته‌شده
- در برخی سیستم‌های قدیمی هنوز پشتیبانی می‌شود
- برای انتقال فایل در شبکه داخلی می‌تواند سریع باشد

**معایب:**
- **ناامن** است
- اطلاعات را رمزنگاری نمی‌کند
- در فایروال و NAT ممکن است دردسر ایجاد کند
- برای اینترنت و داده‌های حساس مناسب نیست

### SFTP

**مزایا:**
- **امن** و رمزنگاری‌شده
- فقط از یک پورت استفاده می‌کند
- امکان آپلود، دانلود، لیست، حذف و تغییر نام فایل را دارد
- برای انتقال فایل حساس بسیار مناسب است

**معایب:**
- نیاز به SSH روی سرور دارد
- ممکن است از FTP کمی کندتر باشد
- برای کپی ساده، نسبت به SCP کمی سنگین‌تر است

### SCP

**مزایا:**
- **امن** و رمزنگاری‌شده
- بسیار ساده و سریع
- برای کپی مستقیم فایل‌ها عالی است
- فقط از یک پورت استفاده می‌کند

**معایب:**
- فقط برای کپی فایل مناسب است
- امکانات مدیریتی فایل ندارد
- معمولاً Resume ندارد
- برای عملیات پیچیده از SFTP ضعیف‌تر است

## 3) برای هر scenario کدام مناسب‌تر است؟

### اگر امنیت مهم است
- **SFTP** یا **SCP** مناسب‌تر هستند.
- اگر فقط کپی فایل می‌خواهید: **SCP**
- اگر علاوه بر کپی، مدیریت فایل هم لازم است: **SFTP**

### اگر فقط انتقال سریع و ساده فایل می‌خواهید
- **SCP** مناسب‌تر است.

### اگر نیاز به مدیریت فایل روی سرور دارید
- **SFTP** مناسب‌تر است.

### اگر در شبکه داخلی و بدون حساسیت امنیتی کار می‌کنید
- **FTP** می‌تواند استفاده شود، ولی فقط در محیط‌های کنترل‌شده.

### اگر اینترنت یا شبکه ناامن در میان است
- **SFTP** بهترین انتخاب است.

### اگر با سیستم‌های قدیمی یا نرم‌افزارهای قدیمی کار می‌کنید
- ممکن است **FTP** لازم شود.
